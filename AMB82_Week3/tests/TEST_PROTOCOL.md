# 第三週測試規範（實測後填寫）

1. 初測 30 次：0、1、2、3、4、5 六種手勢各 5 次；每次重置或放開手勢，避免沿用前次狀態。
2. 重測 10 次：針對初測失敗最多的類別／情境重新測試，記錄調整內容；不得以重測覆寫初測。
3. 條件：一般室內照明、手掌距鏡頭約 50 cm；延伸測試可改為 30/70 cm、背光、側向、遮擋。填入實際距離與光線。
4. target_fingers 為預期手勢（0~5）；actual_fingers 為 Serial Monitor 觀察的實際值，無偵測時填 `none`；預期與實際動作填於 action_expected / action_observed。
5. pass_1_fail_0：完全符合預期填 1，否則填 0；沒有做的測試留空，不能當成成功。
6. 反應時間從手勢穩定呈現到網頁動作發生，以影片逐格或計時工具測量；未量測留空。
7. 0 確認需先選答案，5 下一題需先確認；測試前應設定對應網頁狀態。
8. 無目標情境：手離開畫面至少 2 秒，應不觸發選項／確認／換題。另記錄於 notes 或新增試驗列。
9. 執行 `python tests/analyze_tests.py` 統計初測、重測的真實成功率與平均反應時間。
